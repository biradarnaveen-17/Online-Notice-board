# 📢 Online Notice Board System

## 📖 Introduction
The **Online Notice Board System** is a web-based application designed to replace traditional manual notice boards used in educational institutions and organizations.  
Instead of physically posting notices on boards, administrators can publish notices digitally, and users can access them anytime and anywhere through a web browser.

This system improves communication efficiency, reduces paper usage, and ensures that important announcements are not missed.

---

## ❗ Problem Statement
Traditional notice boards are:
- Time-consuming to update
- Accessible only to people who are physically present
- Prone to damage, loss, or outdated information

There is a need for a **centralized digital platform** that allows instant, reliable, and remote access to notices.

---

## 🎯 Objectives
- To develop a web-based system for digital notice management  
- To allow administrators to post, update, and delete notices easily  
- To provide users with instant and remote access to notices  
- To reduce dependency on paper-based communication  
- To improve information dissemination efficiency  

---

## 🧠 Key Features
- Admin authentication (login system)
- Create, update, and delete notices
- Supports text, image, video, and document notices
- Notice expiration date support
- Department-wise notices
- File upload support
- Secure SQLite database storage
- User-friendly web interface
- Centralized notice management

## 🧩 System Architecture
The Online Notice Board System follows a **client-server architecture**:

- **Admin Module**  
  Used for authentication and notice management.

- **Web Server (Flask)**  
  Handles application logic and client requests.

- **Database (SQLite)**  
  Stores admin credentials and notice details.

- **User Interface**  
  Displays notices to users through a web browser.

---

## 🔄 Methodology
1. **Requirement Analysis**  
   Identify the need for a digital notice management system.

2. **System Design**  
   Design database schema, UI layout, and application flow.

3. **Development**

4. **Database Integration**
